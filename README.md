# 🤖 Бот учёта заправки фреона — Инструкция по запуску

## Что умеет бот

- Мониторит 10-12 Telegram-чатов одновременно
- Распознаёт отчёты: номер машины, объём фреона, сумма денег
- При ошибке формата — задаёт уточняющие вопросы
- Команда `/итог` — статистика текущего чата за сегодня
- Команда `/итогвсе` — сводка по всем чатам (для администраторов)
- Команда `/выгрузка` — Excel-отчёт за день

---

## Шаг 1. Создать бота в Telegram

1. Написать @BotFather в Телеграм
2. Команда `/newbot`
3. Придумать имя и username (например `freon_report_bot`)
4. Скопировать **токен** вида `7123456789:AAF...`
5. Добавить бота в каждый чат и **назначить администратором**
6. В личке с @BotFather отключить Privacy Mode: `/setprivacy` → выбрать бота → `Disable`
   _(без этого бот не видит обычные сообщения в группах)_

---

## Шаг 2. Получить ID чатов

1. Добавить @userinfobot в нужный чат
2. Написать `/start` — он покажет ID чата (отрицательное число вида `-1001234567890`)
3. Записать ID всех чатов

---

## Шаг 3. Арендовать сервер (вне РФ)

**Рекомендация: Hetzner Cloud (Германия)** — ~5€/месяц

### Зарегистрироваться:
1. Зайти на https://www.hetzner.com/cloud
2. Создать аккаунт, привязать карту
3. Создать сервер: **CX11** (минимальный), **Ubuntu 24.04**, регион Германия

### Подключиться по SSH:
```bash
ssh root@ВАШ_IP_АДРЕС
```

---

## Шаг 4. Установка на сервере

```bash
# Обновить систему
apt update && apt upgrade -y

# Установить Python
apt install python3 python3-pip python3-venv git -y

# Создать папку и загрузить файлы
mkdir /opt/freon_bot
cd /opt/freon_bot

# Загрузить файлы бота (скопировать содержимое папки tg_bot)
# Вариант A: через scp с компьютера:
# scp -r tg_bot/* root@ВАШ_IP:/opt/freon_bot/

# Вариант B: создать файлы вручную через nano:
# nano bot.py  (вставить содержимое)

# Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

---

## Шаг 5. Настроить конфиг

```bash
nano config.py
```

Заполнить:
```python
BOT_TOKEN = "7123456789:AAF..."  # Твой токен от BotFather

ALLOWED_CHAT_IDS = [
    -1001234567890,  # Чат Смена 1
    -1009876543210,  # Чат Смена 2
    # ... все чаты
]

ADMIN_IDS = [
    123456789,  # Твой личный ID (узнай через @userinfobot)
]
```

---

## Шаг 6. Запустить как службу (чтобы работал постоянно)

```bash
# Создать файл службы
cat > /etc/systemd/system/freon-bot.service << EOF
[Unit]
Description=Freon Report Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/freon_bot
ExecStart=/opt/freon_bot/venv/bin/python bot.py
Restart=always
RestartSec=10
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
EOF

# Включить и запустить
systemctl daemon-reload
systemctl enable freon-bot
systemctl start freon-bot

# Проверить статус
systemctl status freon-bot

# Смотреть логи в реальном времени
journalctl -u freon-bot -f
```

## Использование

### Формат отчёта от сотрудника:
```
е133уу
Залил 450
взял 3500
```

### Бот принимает и такие варианты:
```
e133yy          ← латиница → автоматически переводит в кириллицу
залил 450г      ← с единицей измерения
взял 3500 руб   ← с припиской
```

### Если формат неверный:
Бот напишет уточняющий вопрос в ответ на сообщение сотрудника.

### Команды:
| Команда | Кто может | Описание |
|---------|-----------|----------|
| `/итог` | Все в чате | Статистика этого чата за сегодня |
| `/итогвсе` | Администраторы | Сводка всех чатов |
| `/выгрузка` | Администраторы | Excel за сегодня |
| `/выгрузка 18.05.2025` | Администраторы | Excel за конкретную дату |
| `/помощь` | Все | Справка |

## Устранение неполадок

**Бот не видит сообщения в группе:**
→ Убедись что Privacy Mode отключён в @BotFather (`/setprivacy → Disable`)
→ Убедись что бот добавлен администратором

**Ошибка подключения к Telegram API:**
→ Проверь что сервер находится вне РФ
→ Проверь токен в config.py

**Посмотреть логи:**
```bash
tail -f /opt/freon_bot/bot.log
# или
journalctl -u freon-bot -n 50
```
